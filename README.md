# ⏱️ Stopwatch using Python (PyQt5)

A sleek and responsive **Stopwatch desktop application** built using **Python** and **PyQt5**.
This project provides accurate time tracking with a modern digital interface and smooth real-time updates.

---

## 🚀 Features

* ⏱️ Real-time stopwatch with millisecond precision
* ▶️ Start, ⏸ Stop, and 🔄 Reset functionality
* ⚡ Updates every 10 milliseconds using `QTimer`
* 🎨 Clean UI with neon green text on black background
* 📐 Responsive layout using `QVBoxLayout` and `QHBoxLayout`
* 💡 Beginner-friendly PyQt5 project

---

## 🛠 Tech Stack

* **Language:** Python
* **Framework:** PyQt5
* **Concepts Used:**

  * GUI development
  * Event-driven programming
  * Timer-based updates
  * Time handling using `QTime`

---

## 🧠 How It Works

* A `QTimer` triggers updates every **10 ms**
* The elapsed time is tracked using `QTime`
* The display is updated dynamically using a `QLabel`
* Buttons control the stopwatch state (start, stop, reset)

---

## ⚙️ Run the Project

```bash
pip install PyQt5
python main.py
```
